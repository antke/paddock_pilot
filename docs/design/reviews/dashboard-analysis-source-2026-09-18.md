## Additional states and limitations to carry forward

- Timeline signal digest displays four signals and a static “+N more” count, with no expansion inside that digest (AnalysisCentre.tsx:826–880). Decide whether this is an intentional summary and provide a clear way to inspect the omitted records. It is not a claim that those records are absent elsewhere.
- Analysis creates a top-level section button for every horse. Fifty long horse names may make navigation dominate; source proves the unbounded control count, not rendered overflow. A searchable horse selector may fit better after a real 50-horse comparison.
- Timeline overview already has named arrow-key controls for moving/resizing its visible window. Do not misreport it as wholly pointer-only. Pointer drag listeners clean up on pointerup but not pointercancel/unmount; verify interruption before adjusting lifecycle ownership.
- Real locked/unlocked/empty analysis, all five care-signal kinds, high-severity attention, overlapping/recurring events, zero filtered chart blocks, long lists, 50 horses, stable switching and midnight updates need explicit fixtures. Analysis arrays and backend overview lists have limits; avoid presenting displayed subsets as complete counts.
- App and stable dashboards have different surrounding auth/query/error composition. A shared command-center screenshot cannot close both. Live approval/decline, access/entitlement, signed URL and persistence checks require controlled accounts/backend data.
