## Confirmed corrections

**Tabs orientation was cosmetic only.** `ui/tabs.tsx` consumed `orientation` but assigned only `data-orientation`; installed Base UI therefore kept its default horizontal context. A real shared-component DOM test failed on missing vertical `aria-orientation`; horizontal manual selection passed. Forwarding `orientation` to Base UI corrects semantics and Up/Down navigation. Two tests now verify vertical automatic selection, disabled selection prevention, horizontal manual selection, and linked panels.

The initial suspicion about `data-horizontal` class selectors was disproved. `src/styles.css` imports `shadcn/tailwind.css`, whose custom variants explicitly match `data-orientation`. The parent’s actual horizontal specimen computed `flex-direction: column`. Existing selectors and horizontal layout are unchanged. The temporary installed-library probe (`/tmp/paddock-tabs-contract-probe.mjs`, output `/tmp/paddock-tabs-contract-probe.log`) proves the emitted attributes, **not** a compiled CSS failure. This distinction matters: raw DOM selector matching alone was insufficient.

**Toasts bypassed the approved font and had undersized close controls.** Parent inspection of real Style Lab success/error notifications at 390px found vendor system sans and a 20×20 close button partly outside the card (`toast-confirmation/before-390.jpg`). Installed Sonner CSS owns those declarations with unlayered attribute selectors. `ui/sonner.tsx` now supplies `var(--font-sans)` on the toaster, reserves trailing space/minimum height on each toast, and overrides the close button to a 44px target inside the trailing edge. Status colors, timeout/pause behavior, vendor state machine, and caller actions remain intact. Two real Sonner DOM tests verify success dismissal/callback and error retry action rather than asserting class strings. Browser font, touch geometry, text clearance and narrow-layout confirmation remain with the parent.

Validation: 4 tests / 2 files passed; scoped ESLint, Prettier and full TypeScript passed. Logs: `/tmp/paddock-tabs-sonner-tests.log`, `-lint.log`, `-types.log`. Before-fix vertical failure: `/tmp/paddock-tabs-before.log`. No backend operations.
